# Security Policy

## Supported Versions

Currently, only the latest version of the application on the `main` branch is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

We take the security of our application very seriously.

If you discover a security vulnerability within this project, please do NOT disclose it publicly on GitHub Issues.

Instead, please send an email to the repository maintainers or use the private vulnerability reporting feature on GitHub if enabled. 
We will review all reports and attempt to address them in a timely manner. We will notify you when the issue has been resolved and the patch has been released.
